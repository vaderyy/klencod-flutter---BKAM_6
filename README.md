# تطبيق بكم؟ — Bikam

تطبيق ويب (Next.js) لالتقاط صورة المنتج ومعرفة سعره فوراً في مختلف الأسواق.

## ما تم تعديله في هذه النسخة
1. **شعار التطبيق**: تم استبدال جميع الأيقونات في `public/icons/` بالشعار الرسمي الجديد (بأحجام 16، 32، 180، 192، 512، وأيقونة Maskable).
2. **شاشة البداية (Splash)**: تم استبدال نص "HELLO" بشعار بكم الرسمي.
3. **تشغيل بدون قاعدة بيانات**: أصبح الاتصال بقاعدة PostgreSQL اختيارياً (تهيئة كسولة) — يعمل التطبيق في Klencod IDE مباشرة، وعند توفر `DATABASE_URL` تعمل ميزة حفظ المنتجات.
4. تحديث اسم الحزمة إلى `bikam-app`.

## التشغيل في Klencod IDE
1. فك ضغط الملف `Bikam_App_Klencod.zip` داخل مجلد المشروع في Klencod IDE.
2. افتح الطرفية (Terminal) ونفّذ:
   ```bash
   npm install
   npm run dev
   ```
3. افتح المعاينة على العنوان الذي يظهر (عادة `http://localhost:3000`).

> ملاحظة: إذا أردت تفعيل حفظ المنتجات في قاعدة بيانات، أنشئ ملف `.env` بمحتوى:
> ```
> DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DB_NAME
> ```

## هيكل المشروع
- `src/components/` — واجهات التطبيق (الكاميرا، السوق، الإضافة، الإعدادات)
- `src/app/api/` — واجهات برمجية (identify, products, health)
- `public/icons/` — أيقونات التطبيق بالشعار الجديد
- `public/manifest.webmanifest` — إعدادات تطبيق الويب (اسم، ألوان، أيقونات)
